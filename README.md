## Qué construyo

Diseño y desarrollo **agentes de inteligencia artificial aplicada** orientados a negocio real: análisis de riesgo país, gestión documental con RAG (*Retrieval-Augmented Generation – Generación Aumentada por Recuperación*), automatización operativa para PYMEs y sistemas de cumplimiento y auditoría asistidos por IA.

## Filosofía de trabajo

> No vendo autonomía ficticia. Construyo sistemas demostrables, con límites documentados, supervisión humana en puntos críticos y arquitectura que puede escalar a producción real.

- Código local-first, ejecutable sin APIs externas obligatorias
- Documentación en castellano, didáctica y trazable
- Tests antes de presentar cualquier pieza como portfolio
- Criterio de madurez explícito: prototipo → muy avanzado → terminado
